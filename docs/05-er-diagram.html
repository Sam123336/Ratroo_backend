Overview

The schema is split into ingestion, staging, identity resolution, and promoted read models.

Rawraw_source_records stores fetched HTML/API payloads before parsing.
Stagedstaged_* tables hold validated canonical records before promotion.
Mappingsprovider_*_mappings preserve stable external-to-canonical identity.
Promotedbus_* and metro_* tables serve public APIs.

Ingestion Flow

Every real provider should move in one direction: raw source to staged canonical records to promoted query tables.

Notes

Current implementation details that matter while debugging imports and schema creation.

UUID v7Every Sequelize model assigns IDs with ensureUuidV7.
Active DatasetPublic routes and stops should be read from the dataset_versions.status = ACTIVE version.
Provenancesource_observations connect raw fetched records to staged canonical records.
PostGISThe legacy stops.location column requires the PostGIS extension.
Remote DB SafetyDB_SYNCHRONIZE=true should only be used intentionally. Production should use migrations.
Full VersionThe complete field-level ERD is maintained in docs/05-er-diagram.md.
