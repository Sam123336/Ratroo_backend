# Admin Dashboard

## Purpose

The admin dashboard is the operating console for data acquisition, provider health, coverage, and community moderation.

## Core Views

| View | Capabilities |
| --- | --- |
| Provider Health | Last import, success rate, error logs, data freshness |
| Import Runs | Job history, payload count, rejected records, retry |
| Coverage Map | State, district, city readiness and gaps |
| Source Catalog | URLs, owners, legal notes, adapter status |
| Data Quality | Duplicate stops, missing coordinates, suspicious route shapes |
| Community Queue | Review corrections, approve/reject, merge records |
| Journey Debugger | Explain why a route was or was not found |

## Operational Metrics

- Import duration
- Import failure reason
- Records created, updated, rejected
- Provider freshness
- Parser version
- Stop coordinate confidence
- Route sequence completeness
- Community moderation backlog
