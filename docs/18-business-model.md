# Business Model

## Public Good Core

The core user experience should remain free for commuters: search, nearby stops, route lookup, journey planning, corrections, and essential alerts.

## Revenue Options

| Model | Description | Risk |
| --- | --- | --- |
| City/agency dashboards | Paid analytics and operations dashboard | Procurement cycles are slow |
| Developer API | Paid high-volume API access | Requires licensing clarity |
| B2B mobility data | Coverage, route, and demand insights | Must protect user privacy |
| Tourism partnerships | Local trip planning and destination bundles | Keep utility experience clean |
| Enterprise commute tools | Office commute planning and shuttle integration | Requires reliability SLAs |
| Sponsored discovery | Contextual, clearly labeled local offers | Must not bias route results |

## Data Ethics

- Do not sell individual movement histories.
- Aggregate analytics must preserve privacy.
- Public transport recommendations must remain unbiased.
- Ads or sponsorships must never alter journey ranking.

## Partnership Targets

- State transport undertakings
- City bus operators
- Metro agencies
- Smart city SPVs
- Universities
- Tourism boards
- Civic tech organizations
